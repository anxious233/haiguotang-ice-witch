## 核心偏好

### 1. 叙事结构：时间/非线性叙事

你偏好的谜题大量使用时间线、倒叙、非线性结构：

| 例子 | 结构特点 |
|------|----------|
| 双蛇玉镯 | 时间跨度 1994-2008 年的日记式叙事 |
| 欺骗的代价 | 1996-2042 年编年体，人生轨迹记录 |
| 独眼 | 时间循环 + 时间跳跃（未来→现在）|
| 时间酒店 | "入住时间为四天"的时间限制规则 |

**创作应用**：汤面不要平铺直叙。使用时间戳、日期、"第一天/第二天"、或倒叙/插叙结构制造悬念。

---

### 2. 叙事视角：非人类/非直觉视角

你偏好的谜题经常使用"视角诡计"：

| 例子 | 视角诡计 |
|------|----------|
| 跳梁小丑 | 主角是监控摄像头 |
| 黑色钱包 | 主角假装盲人，但一低头露馅 |
| 独眼 | 左眼看到未来的能力（时间视角）|
| 时间酒店 | 酒店本身作为生命体的时间规则 |

**创作应用**：主角可以是物体（监控、机器人）、动物（导盲犬视角）、或处于特殊状态的人（盲人、失忆者、精神病人）。视角本身就是谜题的隐藏层。

---

### 3. 人物关系：全员有秘密/全员恶人

你收藏的谜题中，几乎没有"好人"：

- **独眼**：父母利用孩子的超能力牟利
- **跳梁小丑**：小丑家暴孩子，魔术师杀人
- **仰止（全员恶人）**：野兽父子、情侣全员恶人，互相伤害
- **黑色钱包**：凶手设圈套，主角装盲人

**创作应用**：每个出场角色都有秘密。真相揭示时，让读者意识到"原来TA也不是好人"。避免简单的善恶二元对立。

---

### 4. 题材偏好：医学/恐怖/家庭秘密

| 题材 | 例子 |
|------|------|
| 医学恐怖 | 救女（器官捐赠）、独眼（手术摘眼）|
| 家庭暴力 | 跳梁小丑（家暴+谋杀）|
| 家庭秘密 | 双蛇玉镯（母女谜团）、欺骗的代价（代际交易）|
| 规则类恐怖 | 时间酒店（入住规则+死亡规则）|

**创作应用**：医学场景（医院、手术、器官）、家庭内部（母女、父子、夫妻）、封闭空间（酒店、监狱、精神病院）是你的舒适区。

---

### 5. 汤底类型：逻辑反转 + 伦理冲击

你的收藏中汤底大致分两类：

**A. 逻辑型（黑色钱包、独眼）**
- 通过细节（低头的动作）触发逻辑崩塌
- 凶手设局 → 主角破局失败

**B. 伦理型（全员恶人、救女、欺骗的代价）**
- 真相揭露人性的黑暗
- 结局常是悲剧（死亡、失去、无法挽回）

**创作应用**：汤底必须有"啊哈"时刻——可以是逻辑上的顿悟，也可以是伦理上的震惊（"原来TA是这种人"）。

---

### 6. 叙事密度：信息量大，每句都有用

你的收藏中汤面特点是：
- 没有废话，每句话都埋线索
- 看似无关的细节（玉镯、项链、手术）都是伏笔
- 多线并行（主线+暗线），最后汇合

**创作应用**：砍掉所有形容词和渲染。汤面要像代码一样——每行都在做功。

---

### 7. 情绪基调：黑暗、压抑、悲剧

- 无圆满结局
- 受害者不一定是无辜的
- 加害者不一定是邪恶的
- 灰色地带是常态

**创作应用**：不要写"真相大白后大家过上幸福生活"。真相往往更黑暗。

## 创作框架

### 推荐结构：时间线 + 多视角 + 全员恶人

```
汤面结构：
1. 时间锚点（某年/某天）
2. 第一视角叙述（A的日记/A的观察）
3. 第二时间线插入（其他人的视角/记录）
4. 矛盾出现（为什么A看到和B说的不一样？）
5. 结尾钩子（一个无法解释的现象）

汤底结构：
1. 视角诡计揭示（主角不是人/A不是A）
2. 时间诡计揭示（循环/倒叙/平行时间）
3. 伦理冲击（全员恶人/A才是加害者）
4. 悲剧结局（无法挽回的损失）
```

## 示例

### 示例1：监控视角 + 时间回溯

**汤面**：

```
【监控记录 · 7号楼3单元电梯】

2023-06-01 22:17:23
女子进入电梯。按了12楼。低头看手机。

2023-06-01 22:17:45
电梯停在12楼。门开。女子未出。门关闭。

2023-06-01 22:18:12
电梯停在12楼。门开。女子走出。

2023-06-01 22:18:30
电梯停在12楼。门开。女子走进。

2023-06-02 06:00:00
清洁发现电梯内有血迹。
女子从未走出大楼。
```

**汤底**：女子被困在时间循环中。每次电梯门开，她看到不同的时间线。最后一次她选择走进去，因为那一侧是"外面"。

### 示例2：全员恶人 + 医学伦理

**汤面**：

```
母亲的病历（节选）

2020.03.15：配型成功。等待供体。
2020.06.01：供体出现。手术成功。
2020.09.12：排异反应严重。再次等待。
2021.02.28：二次手术成功。
2021.08.15：母亲康复出院。

姐姐的日记（节选）

2020.05.20：妈妈等不了了。我找到一个人。
2020.05.25：他同意了。条件是我跟他走。
2021.02.10：妈妈又要手术。这次不用找人了。
2021.08.01：我回家了。妈妈不认得我。

我的记录：

我没有姐姐。
```

**汤底**："姐姐"是第一任供体（男友/陌生人）。第二次手术的供体来源是——她自己。母亲选择性失忆，因为知道真相。

## 使用方式

当你说"按我的风格写"时，我会：

1. 优先使用时间线/非线性结构
2. 设置视角诡计（非人类视角或身份错位）
3. 确保每个角色都有秘密
4. 汤底有伦理冲击或逻辑反转
5. 基调黑暗，无圆满结局
6. 砍掉冗余描写，每句话都埋线索
