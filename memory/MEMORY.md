### 世界观框架
- 旧时代（≈2050年）气候工程事故加速自然冰河期 → 文明崩塌 → 200-300年断层 → 极端环境激活隐性基因（超能力产生） → 新纪元部落社会
- 核心因果：冰河期是**自然现象**，超能力是冰河期的**产物**（因果反转）
- 核心角色：沉睡者陈觉（旧时代冷冻休眠者）、冰之魔女霜（天然激活的低温操控者）

### 三部曲结构
| | 类型 | 核心诡计 | 关键锚点线索 | 难度 |
|---|---|---|---|---|
| P1 祭品 | 变格 | 魔女存在过但已消失，全球寒冷与魔女无关 | 冰裂之日60年不变（铁证：献祭与气候无因果） | 中 |
| P2 真身 | 变格 | 新的冰系能力者出现，冰河期不断催生能力者 | "你为什么问'谁'？" + 冰的质地差异 | 中偏难 |
| P3 遗言 | 本格/变格混合 | 寒冷→能力（因果反转），魔女是守护者 | 温度↑能力↓ + "晨星"计划 | 困难 |

### 关键创作决策（经8轮迭代收敛）
1. **P1魔女定位**：从"真实存在过的强大能力者"→"纯神话/诅咒叙事"（与能力者泾渭分明，P2才揭示真实存在）
2. **汤面风格**：压缩至500-600字，超能力自然融入生存细节（不叫"能力者"），世界观呈绝望感
3. **谜题驱动方式**：从"一个核心矛盾"改为"多组互相矛盾的观察并置"，冰裂之日为终极锚点
4. **传说口吻**：无具体时间，神话化而非档案记录
5. **啊哈时刻核心**："魔女存不存在不重要，重要的是冷不是她的作品"
6. **跨篇回响**：冰裂之日贯穿三部——P1证明"不变"（献祭无关）、P3预告"即将变"（冰河期终点）
