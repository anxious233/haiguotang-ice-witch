# 冰之魔女 · 海龟汤三部曲

基于《炎拳》冰之魔女概念创作的三个共享世界观横向思维谜题（海龟汤）。

## 世界设定

末期冰河废土——旧文明崩塌数百年后，残存人类形成部落社会。超能力被极端环境激活，科技痕迹存在但弱化。部落将严寒人格化为"冰之魔女"，不知"冰河期"为何物。

核心因果：冰河期是自然现象，超能力是冰河期的产物（因果反转）。

## 三部曲结构

| | 核心谜题 | 类型 |
|---|----------|------|
| P1 · 献祭 | 寒冷是什么？ → 冰河期 | 变格 |
| P2 · 知天者 | 魔女是谁？ → 冰之圣女（表面）/ 屠夫（暗线） | 变格 |
| P3 · 冰之圣女 | 能力从哪里来？ → 寒冷制造了能力 | 本格/变格混合 |
