# 冰之魔女 · 海龟汤三部曲

基于《炎拳》冰之魔女概念创作的三个共享世界观横向思维谜题（海龟汤）。

## 世界观

末世冰河后废土——旧文明崩塌 200-300 年后，残存人类形成部落社会，超能力在极端环境中被激活，科技痕迹存在但弱化。部落将严寒人格化为"冰之魔女"，不知"冰河期"为何物。

## 三部曲结构

| | 类型 | 核心诡计 | 难度 |
|---|------|----------|------|
| P1 祭品 | 变格 | 魔女存在过但已消失，全球寒冷与魔女无关 | 中 |
| P2 真身 | 变格 | 新的冰系能力者出现，冰河期不断催生能力者 | 中偏难 |
| P3 遗言 | 本格/变格混合 | 寒冷→能力（因果反转），魔女是守护者 | 困难 |
